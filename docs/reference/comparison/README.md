# vivarium and the alternatives

Four tools that put a coding agent somewhere it cannot wreck your laptop. A capability name links to the scenario that decides it; a verdict links to what that tool did there.

Every row is read at one isolation class: a microVM with its own guest kernel behind a hardware-virtualization boundary. flake-pilot reaches that class two ways and gets a column for each. What each mark may mean, and why the tables are built this way: [`methodology.md`](./methodology.md).

Legend: ✅ yes · ⚠️ partial · ❌ no · ➖ n/a

- `*` — specified, not built yet
- `†` — a design position rather than an omission; the cell names what forecloses it, or who owns it instead
- `‡` — the mechanism is the tool's and the arrangement is yours; it works, and it works each time because you invoked it
